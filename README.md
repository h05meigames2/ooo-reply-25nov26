Entry for the [Funniest One-Line Out-of-Office Reply](https://make.fun/competitions/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) bounty on [make.fun](https://make.fun).

`main.py` writes a single funny out-of-office auto-reply line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line is fixed and deterministic — the same text on every run, 1–160 characters, one line.

## Run

```sh
python3 main.py
```

## The reply

> I'm away — my inbox is in charge, and it has no experience and even less patience.
